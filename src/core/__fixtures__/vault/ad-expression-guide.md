## 쓰지 않는 표현
효과를 보장하거나 최상급을 쓰는 표현은 답장에 쓰지 않습니다.

```json
{
  "banned": ["100%", {"term": "부작용 없는", "reason": "효과·안전 보장"}, "최고"],
  "warn": ["할인", "후기 이벤트"]
}
```

가상 의원의 예시 문서이며 실제 의료 지침이 아닙니다.
