## 고정 문구
공개 창구에는 치료 내용이 없는 아래 문구만 씁니다.

```json
[
  {"key": "review-thanks", "text": "소중한 의견 감사합니다."},
  {"key": "comment-question", "text": "궁금한 점은 상담 창구로 문의해 주세요."}
]
```

가상 의원의 예시 문서이며 실제 의료 지침이 아닙니다.
