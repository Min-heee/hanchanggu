## 인사와 맺음
인용 없이 쓸 수 있는 문장은 아래 목록뿐입니다.

```json
{
  "greetings": ["안녕하세요, 샘플의원입니다.", "문의 주셔서 감사합니다."],
  "closings": ["더 궁금한 점이 있으면 편하게 문의해 주세요.", "감사합니다."]
}
```

가상 의원의 예시 문서이며 실제 의료 지침이 아닙니다.
