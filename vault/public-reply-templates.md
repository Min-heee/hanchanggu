# 리뷰·댓글 고정 문구

## 왜 고정 문구인가

리뷰나 댓글에 병원이 답글을 달면, 답글 내용만으로 그 사람이 이 병원의 환자라는 사실과 받은 치료가 드러날 수 있습니다. 그래서 공개 창구에는 아래 고정 문구만 씁니다. 고정 문구는 치료 내용, 방문 사실, 개인 상황을 언급하지 않습니다.

## 쓰는 법

리뷰와 유튜브 댓글에는 아래 목록에서 알맞은 문구 하나를 고릅니다. 문구를 고쳐 쓰거나 치료 내용을 덧붙이지 않습니다. 답이 필요한 질문이면 비공개 창구로 문의하도록 안내하는 문구를 씁니다.

## 불만 리뷰

불만 리뷰에도 사실관계를 공개 답글로 다투지 않습니다. 불편에 사과하고 비공개 창구로 연락해 달라는 문구를 쓰며, 내부에서는 해당 건을 따로 확인합니다.

## 공개 댓글에 증상이나 연락처가 있을 때

댓글에 증상이 적혀 있으면 [[handover-procedure]]를 따르고, 공개 답글에는 비공개 창구 안내 문구만 씁니다. 댓글에 연락처 같은 개인정보가 적혀 있으면 [[privacy-notice]]에 따라 처리합니다.

## 기계가 읽는 값

```json
  { "key": "review-complaint", "text": "불편을 드려 죄송합니다. 자세한 내용을 확인할 수 있도록 병원 상담 창구로 연락 주시면 담당자가 안내드리겠습니다." },
  { "key": "comment-question", "text": "관심 가져 주셔서 감사합니다. 개인마다 상황이 달라 댓글로는 답변드리기 어렵습니다. 궁금한 점은 병원 상담 창구로 문의해 주세요." },
  { "key": "comment-thanks", "text": "시청해 주셔서 감사합니다." },
  { "key": "comment-private-info", "text": "개인정보 보호를 위해 댓글의 연락처는 숨김 처리했습니다. 병원 상담 창구로 문의해 주시면 안내드리겠습니다." }
]
```

가상 의원의 예시 문서이며 실제 의료 지침이 아닙니다.
