# 한창구

병원에 들어온 문의에 AI가 병원 안내문과 가격표를 토대로 답장 초안을 쓰고, 직원이 읽어 보고 그대로 보낼지 고쳐서 보낼지 정하는 도구입니다.

> 가상 의원 '샘플의원'과 지어낸 문의 41건으로 만든 견본입니다. 실제 병원 문서나 환자 정보는 없습니다.

**시연:** https://hanchanggu.vercel.app (설치·로그인 없음. AI를 실시간으로 부르지 않고 미리 녹화한 답을 보여 줍니다)

## 기능

- 시연에서는 10개 창구(카카오, 네이버 톡톡, 홈페이지 폼, 전화 메모, 리뷰 등)에서 온 것처럼 지어낸 문의를 급한 순서로 보여 줍니다. 실제 창구 연결은 채널톡 같은 공식 상담 서비스가 필요합니다.
- 병원 안내문 문단을 인용해 답장 초안을 만들고, 금액은 AI가 아니라 가격표에서 넣습니다.
- 증상·약 문의는 의료진 인계 카드(걸린 규칙, 담당, 응답 시한)를 먼저 띄웁니다. AI 초안(환자 말 되짚기 한 문장 + 병원 승인 안내 + 섞인 예약·가격 물음의 안내문 답)은 의료진이 확인해야 보낼 수 있습니다.
- 직원 내부 질문에도 같은 안내문으로 답합니다(사내 Q&A).
- 공개 리뷰·댓글에는 정해진 문구만 제안합니다.

## 믿을 수 있게 만든 장치

- 증상·약 규칙이 AI보다 먼저 돌고, 규칙 목록이 비거나 깨지면 화면과 녹화가 멈춰 AI를 부르지 않습니다.
- 인용이 안내문 원문과 다르거나 숫자·기간이 원문에 없으면 코드가 초안을 보류합니다. 증상·약 초안은 되짚기 한 문장 말고는 안내문 문장을 글자 그대로 옮겨야 하고, 되짚기에 문의에 없는 말·부정 뒤집기·약·판단·지시가 있어도 보류합니다. 옮긴 문장이 그 문의에 맞는 답인지는 의료진이 확인합니다.
- 자동 발송이 없습니다. 직원이 승인해야 보내기 버튼이 켜지고, 증상·약 문의의 초안은 의료진이 확인해야만 켜집니다(모의 — 역할 선택, 로그인 없음).

## 숫자

지어낸 데이터로 잰 값입니다(AI 답은 4회차 녹화 기준. 증상·약 문의 초안은 2026-09-30에 따로 녹화).

| 무엇을 셌나 | 결과 |
|---|---|
| 답이 안내문에 있는데 AI가 멈춘 질문 | 0 / 39 |
| 답이 안내문에 없어서 지어내지 않고 멈춘 질문 | 8 / 8 |
| 인용이 안내문 원문과 다른 초안 | 0 / 46 |
| 의료진에게 넘겨야 하는데 놓친 증상 문의 | 0 / 15 (자기 시험) |
| 증상·약 문의의 의료진 확인용 초안 — 검사 통과 (나머지는 보류) | 15 / 20 |

같은 질문을 보고 지시문과 검색을 고친 뒤 잰 값이라 편향이 있습니다. 세부: [docs/EVALUATION.md](docs/EVALUATION.md)

## 실행 방법

```bash
npm install
npm run dev      # http://localhost:3000
npm run verify   # test + typecheck + lint + build
```

Node `^20.19 || ^22.13 || >=24`. API 키 없이 돌아갑니다([AI 답 녹화 방법](docs/DETAILS.md#실행-방법-세부)).

## 한계

- 실제 병원에서 써 본 적이 없고, 카카오 등 실제 창구 연결과 로그인이 없습니다.
- "해도 됩니다"와 "하면 안 됩니다"처럼 뜻이 뒤집힌 문장은 코드가 못 잡습니다. 사람이 읽고 보내야 합니다.
- 평가 질문·정답 문단·테스트 기대값·초안 품질 판정은 AI가 쓴 초안이고, 사람이 아직 검수하지 않았습니다.
- 증상 같은 건강 정보도 개인정보를 가린 뒤 외부 AI(Anthropic)로 보냅니다. 실제 병원 도입 시 민감정보 처리 위탁·고지·동의가 필요합니다(지금은 가상 데이터라 실제 환자 정보가 없습니다).
